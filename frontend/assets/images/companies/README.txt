Place your company logo files in this folder using these base names:
- dawlance.png / .jpg / .jpeg / .jfif / .webp
- haier.png / .jpg / .jpeg / .jfif / .webp
- super-asia.png / .jpg / .jpeg / .jfif / .webp
- bonus.png / .jpg / .jpeg / .jfif / .webp
- local-machines.png / .jpg / .jpeg / .jfif / .webp

The frontend automatically tries these extensions in this order:
png, jpg, jpeg, jfif, webp, svg

If no real logo file exists, the app falls back to the included SVG placeholder.
